# NumPy: Basic to Advanced Notes

A practical Jupyter Notebook covering NumPy from fundamentals through advanced, data-science-oriented usage.

## Contents

- Array creation, data types, attributes, indexing, slicing, and iteration
- Vectorized operations, aggregation, broadcasting, reshaping, and matrix operations
- Important NumPy functions such as `where`, `unique`, sorting, and `argsort`
- Copy vs. view behavior and performance concepts
- Linear algebra, random number generation, and numerical preprocessing
- Practical examples for student marks and machine-learning dataset preparation
- Common mistakes, interview questions, practice questions, and solutions

## Open the notebook

Open [`NumPy_Basic_to_Advanced_Notes.ipynb`](NumPy_Basic_to_Advanced_Notes.ipynb) with Jupyter Notebook, JupyterLab, or Google Colab.

## Requirements

```bash
pip install numpy jupyter
```
